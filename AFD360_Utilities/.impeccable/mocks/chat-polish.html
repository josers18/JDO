Chat polish: Today vs Proposed

Five fixes from the critique, mocked with the Navy & Gold tokens and the app's fonts. The left column copies what ships today, from the source and the review screenshots. The right column is what would change. Nothing here touches the app.

P1

1 · HXL card wears the Sent lane inside a Received message

Blue means “we sent this.” Today the generated card is blue inside a warm Received message, and it has three frames: the message, the HXL frame and the widget's own box. The proposal makes the card header neutral, since it's content and not a direction, keeps one frame, and keeps the widget type visible in mono.

2 · Wire panel can squeeze the chat

The Wire can be dragged to 60% of the window, and the width is remembered. At 1440px a past wide drag leaves the thread at about 450px. At 1000px the Wire opens as a 544px overlay with no backdrop. The proposal caps the Wire at 45%, never lets the chat drop below 560px, and gives the narrow overlay a backdrop that closes on click or Esc.

3 · Assistant prose runs ~140 characters per line

The thread is 72rem wide, so paragraphs stretch across about 1000px, which is hard to follow on a projector. 5 · Session bar: metadata wrapping and “Live” after days idle

Shown at 640px wide, about what the bar gets at a 1000px window. Today the separators start new lines and the IDs break mid-line. The proposal keeps each item whole, drops the “·” separators in favor of spacing, so a wrapped line never starts with one, and shortens the agent ID (full value on hover). When a session has been idle past the Agent API lifetime, the chip changes to “Likely expired.” The next message confirms either way, because the server already marks the session expired when the API rejects it.
