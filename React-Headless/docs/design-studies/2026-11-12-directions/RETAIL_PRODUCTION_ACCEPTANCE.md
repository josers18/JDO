# Retail Atlas — production acceptance register

November 13, 2026. **All production gates below are pending.** This is a test/evidence specification, not the result of a live acceptance run. The 52 passing standalone selector tests and five browser suites verify captured/local-draft design behavior only; their milestone logs remain the evidence for that narrower scope.

Implement against the [migration contract](RETAIL_MIGRATION_CONTRACT.md), [action mapping](RETAIL_ACTION_CONTRACT.md) and [production plan](../../superpowers/plans/2026-11-13-retail-atlas-production-migration.md). Use a dedicated test org/test data and authorized users before any live send/update/delete; do not use captured customer records as destructive test fixtures. Read-only planning in this milestone does not authorize deployment or external communication.

Each gate requires the tested source commit, bundle/build version, actor/org/effective owner, input record IDs, source periods/scope, expected/actual result, test command/log, and any browser evidence. Do not put credentials or unnecessary customer content into logs. Record failures and unavailable source states; an absent source cannot be marked passed from a fixture.

## Evidence levels and sign-off

- **Design verified:** captured fixture selector/browser checks from Milestones 1–5; no production assertions inferred.
- **Source reviewed:** paths/functions inspected, with explicit known limits and no assumption of deployed equality.
- **Implementation verified:** relevant unit/component/Apex tests and builds for the exact migration commit.
- **Authenticated acceptance verified:** target-org read/write/permission/model checks under authorized actors and test data, with source versions/periods.
- **Release verified:** deployment JSON, app-domain behavior and rollback proof for the deployed revision.

A gate can be pending, passed, failed, or unavailable with reason; unavailable is not passed. A source feature kept on the verified current surface may be deferred from Atlas activation, but its entry must remain reachable and the parity matrix must state that exception. No completion percentage replaces gate evidence.

Activate Atlas only after the relevant gates pass, scope exceptions are explicit, and deployment is authorized. Completion of the documentation milestone alone leaves every production gate pending.
